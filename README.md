# JDBC Learning

This project is created to learn and practice JDBC with Java and PostgreSQL.

## Technologies Used

- Java
- JDBC
- PostgreSQL
- IntelliJ IDEA

## Concepts Learned

- JDBC Driver
- Database Connection
- Statement
- SQL Query Execution
- Closing Database Connection

## What I Built

A simple Java program that connects to a PostgreSQL database
and executes a SELECT query using JDBC.

## How to Run

1. Install Java
2. Install PostgreSQL
3. Create a PostgreSQL database
4. Update the database URL, username and password
5. Run the Java program
